# Document Splitter

Разбор длинных скриншотов документов. Одна такая лента содержит 8–20 страниц
подряд, а инструмент превращает её в отдельные страницы, готовые
к распознаванию.

Делал под свою задачу: документы снимались расширением FireShot из Google Docs
одной лентой шириной 1300–2500 пикселей. Резать вручную неудобно, а обычные
алгоритмы ошибаются. Инструмент специализированный — настройки под свои
документы приходится подбирать самостоятельно.

## Что умеет

Берёт один файл или папку целиком. В папке можно отметить галочками только
нужные файлы.

Находит границы страниц обученной моделью и режет ленту. Картинки внутри
страниц вырезает отдельно.

Дальше страницу можно прогнать через локальную vision-модель в LM Studio —
она превратит её в HTML. Есть два стиля: полный HTML или только текст.
Можно и вовсе без модели: тогда будет нарезка и картинки, без распознавания.

Обработку длинной папки можно поставить на паузу. Картинки сохраняются
отдельно или встраиваются в HTML. Скрипт `html_processor.py` сшивает
страницы в один документ.

## Состав

```
doc_splitter.py          нарезка и распознавание
train_page_detector.py   обучение своей модели: разметка и тренировка
html_processor.py        сшивка страниц в один документ

tests/
├── tune_threshold.py       подбор порога под свой документ
├── test_split.py           нарезка с выводом координат
├── test_detection.py       детекция при разных порогах
├── test_lm_scenarios.py    прогон страницы через LM Studio
├── make_docx_document.py   генератор тестового документа
└── scan_model.py           проверка файла модели на метаданные
```

## Зачем обученная модель

Первое, что приходит в голову — резать документ по пустым полосам между
блоками текста. Это не работает.

Внутри страницы тоже есть крупные пустые промежутки между разделами, и такая
нарезка рубит страницу пополам. А между настоящими страницами граница может
быть почти незаметной, если на ней картинка или таблица.

Поэтому модель обучена находить именно границы страниц. Она смотрит
на структуру, а не на количество белого.

## Настройки

Порог уверенности задаётся в `doc_splitter.py`:

```python
CONFIDENCE = 0.9          # для поиска страниц
NESTED_CONFIDENCE = 0.45  # для поиска картинок внутри страниц
```

Если модель находит не все страницы — порог можно понизить. Если находит
лишнее — повысить. Подобрать под свой документ поможет `tests/tune_threshold.py`:
он прогоняет файл при разных порогах и показывает, что получается.

## Установка

Нужен Python 3.12. Для нарезки достаточно PyTorch и OpenCV:

```powershell
pip install torch torchvision opencv-python numpy
```

Для распознавания страниц нужен запущенный LM Studio с vision-моделью
на `localhost`. Программа обращается к нему по HTTP.

## Запуск

```powershell
python doc_splitter.py
```

Откроется окно: выбор файла или папки, список файлов, кнопки нарезки
и распознавания.

## Обучение на своих данных

Если стандартная модель плохо работает на ваших документах, можно обучить
свою:

```powershell
python train_page_detector.py
```

Программа откроет окно разметки: отмечаете границы страниц на скриншотах,
затем запускаете обучение. Готовая модель сохранится в `models/`.

## Проверка

```powershell
python tests/test_split.py              # нарезка с координатами
python tests/test_detection.py          # детекция при разных порогах
python tests/tune_threshold.py файл.png # подбор порога
```

## Ограничения

Инструмент делался под документы из Google Docs, снятые FireShot. На других
документах может потребоваться подбор порога или обучение своей модели.

Модель обучена на узких вертикальных лентах, соотношение сторон около 0.18.
Слишком широкие скриншоты она разбирает хуже.

## Чужие документы

Если обрабатываете документы других людей, помните: нарезка и распознавание
идут полностью локально. Изображения никуда не отправляются, LM Studio
работает на вашем компьютере.
